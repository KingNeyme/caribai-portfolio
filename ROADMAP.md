# Roadmap

The portfolio spans six focus areas, from data analytics to AI engineering and research.
Each project solves a realistic problem for a Caribbean business, end to end.

← [Back to the portfolio](README.md)

---

## How every project is delivered

1. **Business first.** Each project starts from a client's question: *who is asking, what
   decision are they making, and what would change their mind?*
2. **Data you can trust.** Raw data is never edited. Every quality issue and cleaning
   decision is documented.
3. **Reproducible.** Each project has its own conda environment (`environment.yml`), and
   notebooks run top to bottom.
4. **Actionable output.** Findings end in specific recommendations and a tool the client
   can keep using.
5. **Published in three places:** the code here on GitHub, a case study on
   [caribailabs.com](https://caribailabs.com), and datasets and notebooks on Kaggle.
